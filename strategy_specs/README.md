# Strategy specs — index

One paper-side spec per strategy, written from the paper rather than from the code. **These
specs are the reference for any strategy rule, ahead of every other document in the
repository.** The SSRN PDFs are not redistributed (SSRN's terms allow a personal download, not
a public copy); each spec links its paper, and page numbers refer to that PDF.
